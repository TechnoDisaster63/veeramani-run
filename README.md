# Veeramani Run: COD Chase

A meme runner game. COD delivery agents chase Veeramani for their cash-on-delivery money. He is not paying today.

Play: https://technodisaster63.github.io/veeramani-run/

Tap / Space = jump (double-tap = double jump). Grab rupee coins to buy distance. Get caught = COD payment force-collected. Made for fun, not real footage.
